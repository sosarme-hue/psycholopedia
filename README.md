# Psycholopedia

Enciclopedia de psicología en castellano (raíz) e inglés (/en/). «Comprender la mente. Entender la vida.»

- `src/data/*.js`: contenido bilingüe (historia, figuras, explorar, vida cotidiana, participar).
- `node build.js` genera la web estática en `dist/`; `PREVIEW=1 node build.js` genera `preview/` con enlaces a `index.html`.
- Sin dependencias ni claves en el repositorio. Lleva Google AdSense (ca-pub-6250668607782976): código en <head>, ads.txt y apartado en Privacidad.
